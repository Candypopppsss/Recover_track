ONE-TIME DEPLOYMENT SETUP

Set the deployment key.

Create an encryption key in this browser, then add it to your Vercel project. This page does not send or save the key.

Already have saved recovery records?

Keep the existing key. A new key cannot unlock records encrypted with a different key. If the original key is missing, restore its backup before proceeding.

01 / CREATE LOCALLY

Generate a private key

Use this only for a new store or first-time setup where no encryption key has been saved.

Keep this private. The field clears when you leave or reload this page. Copying is an explicit action; generating a key does not copy it.

02 / ADD TO VERCEL

Save it in your project

  1. 1
    Open your RecoverTrack project in Vercel, then choose Settings → Environment Variables.
  2. 2
    Add a variable named DATA_ENCRYPTION_KEY. Paste the copied key as its value and select the Production environment.
  3. 3
    Save the variable, then redeploy the latest production deployment. Existing deployments do not automatically receive a newly saved variable.
  4. 4
    Save a private backup in your password manager. Keep the same key for future deployments and database restores.
No backup is stored here.

If you lose the key, encrypted records cannot be recovered by generating another one.
